## Fixture

The assessment PDF contains synthetic questions written for this project. Its matching MP3s were prerecorded with the macOS Samantha voice; they exercise local playback without cloud credentials. In cloud mode uploaded assessment speech is generated by Google Cloud Text-to-Speech.

The public voice samples were generated with Google Cloud Text-to-Speech from one synthetic demonstration sentence. They contain no assessment or personal data and require no synthesis request when played.
